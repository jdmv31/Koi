## 🚀 Descripción
Koi es una aplicación desarrollada en C++/CLI con Windows Forms que recomienda videojuegos a los usuarios basándose en:
- Historial de juegos vistos
- Preferencias de género
- Calidad y precio de los juegos
- Comparación con usuarios con gustos similares

## ✨ Características
- ✅ Sistema de recomendación personalizado
- ✅ Filtrado por género, precio y calidad
- ✅ Interfaz intuitiva y amigable
- ✅ Sistema de seguimiento de historial
